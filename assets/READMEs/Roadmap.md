# Coditan's Roadmap

> [!Note]
> **Note:** This roadmap is not guaranteed to be accurate and is subject to change at any time.

---

## Beta Timeline Overview

| **Beta** | **Target Timeline** | **Primary Focus** |
|:---------|:-------------------|:-----------------|
| **Beta 1** | Bug collection & early feedback |
| **Beta 2** | Stability & optimization improvements |
| **Beta 3** | New features & user experience |
| **Beta 4** | Final polish & launch preparation |

---

## Beta 1 

**Purpose:** The first public beta to gather early feedback and catch bugs that may have slipped through testing.

### Goals
- [ ] Fix all known bugs
- [ ] Develop better tools for community skills
- [ ] Learn from user feedback and needs

---

## Beta 2 

**Purpose:** Focus on stability improvements and optimization based on Beta 1 feedback, plus introducing new features.

### Goals
- [ ] Improve overall stability
- [ ] Better performance optimization
- [ ] Add more customization options
- [ ] Enhance automations system

---

## Beta 3 

**Purpose:** Introduce major new features and prepare for final release with emphasis on user experience.

### Goals
- [ ] Improve context saving features based on feedback
- [ ] Focus heavily on user experience for non-programmers
- [ ] Collect and document final bugs

---

## Beta 4 

**Purpose:** Final bug fixes and community-requested features before official 1.0 release.

### Goals
- [ ] Fix all remaining bugs
- [ ] Add community-requested features
- [ ] Finalize the user interface
- [ ] Make custom actions/skills easier to create and upload

---

## What to Expect

Each beta builds on the previous one:
- **Beta 1** = Feedback gathering phase
- **Beta 2** = Stability & speed improvements
- **Beta 3** = New major features
- **Beta 4** = Final refinements & launch readiness
