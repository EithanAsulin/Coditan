# Making your first AI Key
This guide explains what is an API key using friendly & understandable examples with a full step-by-step guide.

## Introduction
**What is an AI Key?**
For a simple example we'll use a **restaurant** as an example, So think of it like :

| **Role** | **The Action** |
|:---------------|------------|
| **You (The customer)** | You're the customer and you want food, but you can't go into the kitchen directly to get the food. |
| **The AI Key (The waiter)** | The waiter takes your order (the prompt), delivers it to the kitchen, and then brings the food (the response) back to you. |
| **The Server (The kitchen)** | The kitchen has the ingredients and recipes (AI Models), But only the waiter can enter and get the food |



Now think of it as **Instead of food you're ordering messages and recieving response.**
